MVSI technical review: test site

A working answer to each of the five technical questions MVSI raised about Amplitude for KYB onboarding forms, plus a comparison with LogRocket. Every page is static, the source is public, and every Amplitude request the pages make is visible in your browser's network tab or in the in-page inspector.

Context: MVSI runs know-your-business onboarding journeys for many client tenants, with forms containing hundreds of fields. The questions below came from their CTO's team. Work through them in order; each page ends with a link to the next.

How this site is built

  • Plain HTML, CSS and JavaScript with no build step, hosted on GitHub Pages. Source: shermozle/mvsi-testing.
  • SDKs load from Amplitude's CDN exactly as a customer would deploy them, so WebPageTest sees a realistic waterfall.
  • Data goes to one dedicated Amplitude demo project. The API key is in assets/config.js; browser API keys are public by design.
  • The form is fictional. Please don't type real identity or bank details into it, even though masking would catch most of them.
